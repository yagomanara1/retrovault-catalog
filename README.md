# Catálogo da Loja de ports do RetroVault

Índice de **99 ports e recompilações de código aberto** que a Loja de ports do RetroVault
mostra. Cada item leva ao projeto original, e **todo o crédito é de quem fez cada port**.

> **Este repositório não hospeda nenhum programa nem jogo.** Ele guarda só uma lista de links
> (`catalog.json`). Quando você instala um port pela Loja, o arquivo vem direto da página de versões
> do projeto original no GitHub. Para jogar, você precisa da **sua própria cópia** do jogo.

## Créditos

- **Cada port** é obra dos autores listados abaixo. Visite o projeto para conhecer, apoiar ou reportar problemas.
- **Seleção:** boa parte da lista foi escolhida a partir do ranking do
  [Quiver Launcher](https://quiverlauncher.com), um launcher da comunidade para ports e recompilações de jogos para PC.
  Este catálogo não é afiliado ao Quiver Launcher.

Você é autor de um destes projetos e quer corrigir alguma informação ou tirar o seu da lista?
Abra uma issue neste repositório.

## Como usar no RetroVault

Em **Configurações → Loja de ports → Catálogo online**, cole o endereço abaixo e clique em **Testar e usar**:

```
https://github.com/yagomanara1/retrovault-catalog/blob/main/catalog.json
```

## Ports

"Você precisa de" diz o que o port pede da sua cópia: a ROM, os arquivos do jogo, ou nada (jogos livres).
"Feito com IA" segue o que o próprio projeto declara. O app avisa antes de baixar os que foram gerados por IA.
"No Quiver" leva à página do port no Quiver Launcher, com as avaliações da comunidade.
